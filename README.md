# UCHASTOK for Hermes

Переносимый Agent Plugin v1 для подключения Hermes Agent к UCHASTOK MCP — сервису
данных о земельных участках России. Плагин предоставляет шесть инструментов сервера:

- `parcel_profile` — профиль участка по кадастровому номеру;
- `parcel_restrictions` — зоны и ограничения;
- `resolve_point` — поиск участка по координатам;
- `analyze_environment` — анализ произвольного контура;
- `list_layers` — реестр слоёв НСПД;
- `explain_rules` — объяснение правил риск-движка.

Hermes подключается к `https://zu.aigogo.ru/mcp/` штатным MCP-клиентом. Завершающий
слэш обязателен.

Дополнительный нативный инструмент `analyze_zouit_intersections` получает через
REST геометрию участка и пяти видов ЗОУИТ, после чего рассчитывает в Shapely:

- площадь пересечения с каждой зоной;
- долю участка внутри каждой зоны;
- объединённую площадь всех ЗОУИТ без двойного счёта перекрытий.

Инструмент `analyze_social_infrastructure` строит в Shapely минимальную
описывающую окружность участка, увеличивает её радиус на 1000 метров и проверяет
полученные от UCHASTOK объекты социальной инфраструктуры. Для объекта внутри
целевой окружности выводится кратчайшее расстояние от участка, для объекта
снаружи — `∞`.

## Пакет из кадастровых номеров

Нативная команда плагина собирает до 100 (и при необходимости больше) участков
без участия LLM. Она сохраняет исходный ответ API, нормализованные таблицы и
обезличенные задания для внешней разметки. Создайте CSV:

```csv
cadastral_number
52:18:0070045:174
52:18:0070045:175
```

Запустите сбор в том же окружении, где установлен Hermes:

```bash
conda activate designing_multi_agent_systems_hermes
hermes uchastok batch \
  --input cadastral_numbers.csv \
  --output ./uchastok_dataset \
  --run-id pilot-001 \
  --dataset-version investment-v1 \
  --depth standard \
  --workers 2
```

При прерывании повторите команду с тем же `--run-id` и флагом `--resume`.
Уже завершённые участки загружаться повторно не будут. Для бережного отношения
к тестовому API начинайте с `--workers 1`; допустимый диапазон — 1–4.

Результат имеет следующую структуру:

```text
uchastok_dataset/
├── dataset.duckdb                     основное хранилище и статусы
├── raw/<кадастровый_номер>/           неизменённые ответы API
├── processed/<run>_*.parquet          таблицы для анализа
├── labels/*_annotation_tasks.jsonl    карточки внешней разметки
├── labels/*_annotation_schema.json    контракт ответа разметчика
├── labels/*_guidelines.md             правила для 3–4 разметчиков
└── runs/<run>/manifest.json           итог конкретного запуска
```

В задания не включается автоматический `score.total`, чтобы не подсказывать
оценку людям. Идентификатор ответа должен быть парой `task_id + annotator_id`.
Результаты разметки следует хранить отдельно от исходных данных; согласованную
оценку можно получить медианой, а задания с разбросом общей оценки на 2 балла и
более отправить на арбитраж.

## Интерактивная панель

После сбора откройте панель анализа над существующей DuckDB-базой:

```bash
hermes uchastok dashboard --dataset ./uchastok_dataset
```

По умолчанию интерфейс доступен на `http://127.0.0.1:8501`. В нём есть фильтры,
KPI полноты загрузки, сравнение участков, диаграммы ЗОУИТ и инфраструктуры,
карточка с рисками, карта исходных геометрий и выгрузка выборки в CSV.

На удалённом сервере безопаснее оставить локальный адрес и открыть SSH-туннель:

```bash
# На сервере
hermes uchastok dashboard --dataset ./uchastok_dataset --host 127.0.0.1 --port 8501

# На локальном компьютере
ssh -L 8501:127.0.0.1:8501 USER@SERVER
```

После этого откройте `http://127.0.0.1:8501` локально. Если порт публикуется
через `--host 0.0.0.0`, ограничьте доступ файрволом или обратным прокси с
аутентификацией.

## Установка

Из опубликованного Git-репозитория:

```bash
hermes plugins install OWNER/REPOSITORY --enable
```

Для локальной разработки скопируйте или создайте симлинк репозитория в каталог
`~/.hermes/plugins/uchastok`, затем включите плагин:

```bash
python -m pip install -r requirements.txt
export UCHASTOK_API_KEY="ваш-ключ"
hermes plugins enable uchastok
```

После перезапуска Hermes проверьте регистрацию инструментов:

```bash
hermes tools list
```

Пример запроса агенту:

> Получи исчерпывающую информацию об участке 52:18:0070045:174, включая все
> ограничения, окружение, риски, оценку и сведения о полноте данных.

Для исчерпывающего запроса встроенный skill предписывает использовать
`parcel_profile` с `depth=full` и `include_environment=true`. Доступность глубины
`full` зависит от тарифа сервиса.

Для вывода площадей ЗОУИТ попросите:

> Рассчитай площади пересечения всех ЗОУИТ с участком 52:18:0070045:174.

Для анализа социальной инфраструктуры:

> Построй целевую окружность для участка 52:18:0070045:174 и покажи расстояния
> до объектов социальной инфраструктуры, используя ∞ для объектов снаружи.

Геометрический расчёт использует локальную равноплощадную проекцию LAEA. Это
необходимо, поскольку исходный GeoJSON приходит в WGS84, а площадь координат в
градусах нельзя интерпретировать как квадратные метры.

## Важные ограничения

- Данные НСПД не являются выпиской из ЕГРН и не имеют юридической силы.
- Частичный результат обозначается `meta.partial=true`; неполученные разделы
  перечисляются в `meta.missing_blocks`.
- Пустой раздел не доказывает отсутствие ограничений.
- MCP-ответ намеренно не содержит геометрию зон и полные списки объектов. Полная
  геометрия доступна через REST API UCHASTOK.

## Структура

```text
plugin.json                переносимый манифест Agent Plugin v1
mcp.json                   конфигурация Streamable HTTP MCP
plugin.yaml                манифест нативного инструмента Hermes
__init__.py                регистрация инструмента и skill
schemas.py                 JSON Schema инструмента
tools.py                   REST-загрузка и расчёт Shapely
batch.py                   возобновляемый сбор, DuckDB и Parquet
cli.py                     команда `hermes uchastok batch`
dashboard.py               интерактивная панель Streamlit
tests/                     геометрические unit-тесты
skills/uchastok/SKILL.md   правила запроса и интерпретации данных
```
